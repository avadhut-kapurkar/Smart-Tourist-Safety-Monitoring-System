# Smart Tourist Safety Monitoring System

An Android-based project designed to improve tourist safety using modern technologies such as AI, geofencing, maps, and blockchain concepts.

## Project Overview

The Smart Tourist Safety Monitoring System is developed to support tourists during travel by providing safety-oriented features and quick access to important services.

## Technologies Used

- Java
- Android Studio
- Firebase Authentication
- Google Maps
- Geofencing
- AI integration
- Blockchain concepts
- SharedPreferences

## Main Features

- Tourist login and authentication
- Tourist safety dashboard
- SOS/emergency assistance
- Location and map support
- Geofencing-based safety monitoring
- Emergency contact support
- AI-based assistance
- Blockchain-based identification concept
